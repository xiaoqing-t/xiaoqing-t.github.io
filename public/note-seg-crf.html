中文分词与 CRF：从查词典到整句打分

一句话主线：分词是一条从规则到统计、再到判别式的路线——先查最长词，再选最短路径，用语言模型打分；最后把「切词」换成「贴标签」，让 CRF 在整句上给标签序列打分，用动态规划找最高分。

记号约定：一句话写成 $X=(x_1,\dots,x_N)$，$N$ 是字数；标签序列写成 $Y=(y_1,\dots,y_N)$，$S$ 是标签集大小。切分结果用斜杠分隔，视频里统一叫「标签」，公式里用 $Y$。

0. 中文为什么要分词

英文的单词之间有空格，中文没有。一句话进来是一串连续的汉字，下游的检索、句法分析、命名实体识别都按「词」工作，所以先得把字串切成词。

难的地方不在切，而在「不只一种切法」。以「南京市长江大桥」为例：

  • 南京市 / 长江大桥（两个词）
  • 南京 / 市长 / 江大桥（三个词）

两条都说得通，可下游只认一种。更麻烦的是词典里没有的新词——人名、地名、网络新词，规则方法只能干瞪眼。所以分词的难点归结为两条：切分歧义和未登录词。

1. 查词典：最大匹配

最早的办法是查词典，叫最大匹配（正向最大匹配，FMM）：从左往右，每次取能匹配上的最长词，切掉，继续往后走。

拿「他是研究生物化学的」试一下，词典里同时有「研究」「研究生」：

  1. 开头是「他」，最长匹配「他」，切掉；
  2. 接下来是「是」，最长匹配「是」，切掉；
  3. 「研究生」在词典里，「研究」也在，取长的，切出「研究生」；
  4. 剩下「物化学的」，按同样规则得到「物化 / 学 / 的」。

结果是「他 / 是 / 研究生 / 物化 / 学 / 的」，而正确答案是「他 / 是 / 研究 / 生物 / 化学 / 的」。错因很清楚：每次只顾往长里取，没有回头看的机制。第三步多取了「生」，后面的「生物」就没了。

把方向反过来，从右往左切，叫逆向最大匹配（BMM）。两种方法的结果常常不一样，但谁也没有本质上的优势——错误一旦发生，规则方法没有自纠能力。

最大匹配的优点是简单、快、只要一张词表；缺点是歧义处理差、对未登录词束手无策，而且完全依赖词典的质量。

2. 最短路径

换统计的思路：不急着做决定，先把所有切法列出来。

把句子的每个字间位置画成节点，一个词就是一条从位置 $i$ 到位置 $j$ 的边。从开头走到结尾，每经过一条边，就是一种切法。这张图没有环，叫有向无环图（DAG）。

在所有路径里，选边数最少的那条——也就是切出来的词最少：

$$W^{*}=\arg\min_{W\in\mathcal{W}(X)}|W|$$

「南京市 / 长江大桥」经过两条边，「南京 / 市长 / 江大桥」经过三条，所以选前者。词少通常说明切得合理，但这只是直觉：两条路径词数相同时，它又没主意了。而且「词少」并不总等于「切得对」，词组和词在长度上没法区分。

3. 语言模型：给切法打分

最短路径只数边，不看词本身。语言模型法往前走一步：给每种切法算一个概率，选最大的。

句子确定了，词序列的概率就是整句的概率。按链式法则拆开，再用马尔可夫假设近似：

$$P(W)=\prod_{t=1}^{|W|}P(w_t\mid w_{<t})\approx\prod_{t=1}^{|W|}P(w_t\mid w_{t-1})$$

实际实现里就是二元或三元语言模型：给「南京市 / 长江大桥」和「南京 / 市长 / 江大桥」各打一个分，取高的那条。概率通常在字典里查，未见过的组合要平滑，思路和 n-gram 一样。

问题是候选太多。一个字串的合法切法随长度指数增长，不可能全算。工程上用束搜索：从左往右逐个词扩展，每一步只保留分数最高的前 $k$ 条候选，最后取最好的一条。

束搜索是近似解：被剪掉的候选里可能藏着全局最优。$k$ 越大越接近精确解，代价是计算量。

4. 换视角：BMES 序列标注

上面三种方法都离不开词典，词典里没有的新词仍然是死穴。于是换个角度：不切词，改成给每个字贴标签。

标签含义例
B词首（begin）「研」在「研究」里
M词中（middle）三字词中间的字
E词尾（end）「究」在「研究」里
S单独成词（single）「他」「是」「的」

「他 / 是 / 研究 / 生物 / 化学 / 的」就对应标签序列 S S B E B E B E S。标签贴完，词边界自然出现：B 的前面和 E 的后面就是切点。也有更简单的 BI 标记，只用两个标签，适合词长分布比较集中的场景。

换成标注以后，模型不再需要「这个词在不在词典里」这种硬条件，而是学「什么样的上下文对应什么标签」。新词也有上下文，所以能处理。

5. 整句判断：CRF

但标签不能乱贴。B 后面如果直接跟 S，「研」开头的词就只有半个，中间断掉了。也就是说，标签之间存在约束：相邻标签的搭配不是任意的。

所以要在整条序列上一起判断，而不是每个字独立分类。

上一集《词性标注与 HMM》里的 HMM 是生成式模型：它为整句 $P(X,Y)$ 建模，再用贝叶斯换成 $P(Y\mid X)$。条件随机场（CRF）换了个方向，直接建条件概率：

$$P(Y\mid X)$$

给定观测 $X$，哪条标签序列 $Y$ 最可能。观测不再需要建模，模型把全部力气花在「标签怎么配」上。这是判别式模型的基本姿态。

6. 无向图与最大团

CRF 是无向图模型。图里的节点是标签，边表示依赖。

图里两两相连的一组节点叫团（clique），不能再加入新节点还保持两两相连的，叫最大团（maximal clique）。

Hammersley–Clifford 定理说：满足图上的条件独立，联合概率就能按最大团分解成一组非负函数的乘积。序列排成一条链，每个最大团就是相邻的两个标签 $(y_{t-1},y_t)$，对应的模型叫线性链 CRF：

$$P(Y\mid X)=\frac{1}{Z(X)}\prod_{t=1}^{N}\psi_t(y_{t-1},y_t,X)$$

第一步只到乘积，还没归一化；分母 $Z(X)$ 下面再说。

7. 势函数与配分函数

每个最大团配一个势函数 $\psi_t$。它不是一个概率，只是一个非负的分数，构造方式是「特征加权求和，再取指数」：

$$\psi_t(y_{t-1},y_t,X)=\exp\Big(\sum_k w_k f_k(y_{t-1},y_t,X,t)\Big)$$

$f_k$ 是特征函数，$w_k$ 是它对应的权重。取指数保证分数为正，加权求和让多个特征可以叠加贡献。

所有势函数乘起来 $\prod_t\psi_t$，再除以配分函数 $Z(X)$，就得到条件概率。$Z$ 是对所有标签序列求和：

$$Z(X)=\sum_{Y}\prod_{t=1}^{N}\psi_t(y_{t-1},y_t,X)$$

它的作用是保证概率加起来等于一。标签有 $S$ 种、句子有 $N$ 个位置，标签序列一共 $S^N$ 条，逐个求和是指数级——所以 $Z$ 要靠动态规划算，见第 9 节。

8. 特征：CRF 最强的地方

整个模型最关键的部件是特征函数 $f_k$。它不只看当前字，还能看：

  • 当前字本身，以及它的前后各一个字；
  • 前后两个字的组合，例如「研 + 究」；
  • 这个字在不在词典里，是不是数字、字母、标点；
  • 它在句子的哪个位置，是不是句首、句尾；
  • 词性、偏旁部首等外部特征。

这些特征都可以看整条观测 $X$，不受「只看当前字」的限制。实用系统有 106 到 107 量级的特征，靠特征模板批量生成：模板写「当前字 = ?」「前一字 = ?」「当前字在词典里 = ?」这样的模式，遍历语料自动展开。

对比 HMM：发射概率 $P(x_t\mid y_t)$ 只看当前字，转移只看前一个标签。同一个字在不同上下文里长得一样，HMM 就分不出来——这正是 CRF 更强的原因。

9. 算法同构：$\sum$ 与 $\max$

CRF 有两个典型问题，都在同一张网格上做动态规划。

求配分函数用前向算法。定义为「到第 $t$ 个位置、标签为 $j$ 的所有前缀路径分数之和」：

$$\alpha_t(j)=\sum_{i}\alpha_{t-1}(i)\,\psi_t(i,j),\qquad Z(X)=\sum_j\alpha_N(j)$$

求最优序列用维特比。把 $\sum$ 换成 $\max$，同时记下每个格子的最优前驱（回指针），最后从终点倒着走回起点：

$$\delta_t(j)=\max_i\big[\delta_{t-1}(i)\,\psi_t(i,j)\big]$$

两个递推的复杂度都是 $O(NS^2)$：$N$ 个位置，每个位置 $S$ 个标签，每个标签枚举 $S$ 个前驱。指数级的枚举变成多项式级的递推，靠的是「每个格子只留一个最优值（或一个和）」。

维特比求最优标签序列时，$Z(X)$ 可以整个扔掉：它只和观测有关，和候选标签序列无关，比大小的时候是常数。需要概率数值时，才用前向算法把它算出来。

10. HMM 是 CRF 的特例

把 HMM 的联合概率写成无向图的团分解：

$$\psi_t(y_{t-1},y_t)=P(y_t\mid y_{t-1})\cdot P(x_t\mid y_t)$$

再令 CRF 的特征为 $f_1=\log P(y_t\mid y_{t-1})$、$f_2=\log P(x_t\mid y_t)$，权重 $w_1=w_2=1$，取指数之后两个势函数完全一样；HMM 是生成式模型，天然归一化，所以 $Z=1$。

换句话说：HMM 就是「特征取对数概率、权重固定为 1、没有配分函数」的线性链 CRF。

这也解释了为什么维特比、前向、后向可以原封不动搬过来：算法结构只依赖链式图，不依赖势函数是「数出来的概率」还是「学出来的 exp 加权」。HMM 的三张表 $\pi$、$A$、$B$，在 CRF 里换成了一组特征权重 $w$。

11. 评价：P、R、F1

分词怎么评价？看切出来的词对不对。以词为单位统计：系统切出 $N$ 个词，标准答案有 $M$ 个词，两边完全相同的词有 $n$ 个。标准答案里没有的词算错，切法差一个字也算错。

指标公式回答的问题
准确率 P$n/N$我切出来的词里，有多少是对的
召回率 R$n/M$标准答案里的词，我找回了多少
F1$2PR/(P+R)$两边的调和平均

只看一个会出问题：全切成单字，召回率很高但准确率低；只切最有把握的长词，准确率高但召回率低。所以取调和平均。课件里的例子是准确率 78.3%、召回率 91.4%、F1 84.3%——F1 偏向较小的一方，一高一低拉不上去。

在 SIGHAN 2005 中文分词评测上，语言模型法的准确率是 89.8%，CRF 是 94.3%，相差 4.5 个百分点。提升主要来自特征：CRF 能看前后文、词典和位置，语言模型只能看词序列本身。

12. 常见错误

  1. 以为最大匹配会自己纠错。它没有回看机制，一次切长就可能连带错一串。
  2. 把「词最少」当成正确答案。最少只是启发式，词数相同的路径它无法区分。
  3. 以为束搜索一定找到全局最优。被剪掉的候选里有可能是最优解。
  4. 把 BMES 当成四个独立分类器。标签之间有约束，B 后面直接接 S 会产生半个词。
  5. 把势函数当概率。$\psi_t$ 只是非负分数，必须除以 $Z$ 才归一化。
  6. 把 $Z$ 写成对一条序列求和。$Z$ 要对所有 $S^N$ 条标签序列求和，实际用前向算法递推。
  7. 把维特比当前向。一个取 $\max$ 找路径，一个取 $\sum$ 算总概率；网格一样，运算不一样。
  8. 把 $O(NS^2)$ 写成 $O(S^N)$。前者是动态规划，后者是暴力枚举。

13. 自测 8 题

  1. 中文分词的两个核心难点是什么？各举一个例子。
  2. 最大匹配为什么会把「研究生物化学」切成「研究生 / 物化 / 学」？
  3. 最短路径法在什么情况下会失效？
  4. BMES 标记里，词边界由哪些标签决定？
  5. 为什么标签不能每个位置独立判断？
  6. 写出线性链 CRF 的条件概率，并说明 $\psi_t$ 和 $Z$ 各是什么。
  7. 前向算法和维特比在递推上的唯一区别是什么？
  8. HMM 对应 CRF 的哪组特征和权重？为什么此时 $Z=1$？
答案
  1. 切分歧义（南京市 / 长江大桥 与 南京 / 市长 / 江大桥）和未登录词（词典里没有的人名、新词）。
  2. 每个位置只取能匹配的最长词：先取「研究生」，「生物」就被拆掉了；后面同理得到「物化 / 学」。
  3. 两条路径边数相同的时候，「词最少」分不出高下；而且词少不一定切得对。
  4. B 的前面、E 的后面；S 本身前后都是边界。
  5. 相邻标签有约束，例如 B 后面不能直接接 S，否则词被切成两半；一个位置的选择会影响邻居。
  6. $P(Y\mid X)=\frac{1}{Z(X)}\prod_t\psi_t(y_{t-1},y_t,X)$；$\psi_t=\exp(\sum_k w_k f_k)$ 是最大团的分数，$Z(X)=\sum_Y\prod_t\psi_t$ 是配分函数。
  7. 合并前驱时，前向取 $\sum$，维特比取 $\max$；其余递推形式相同。
  8. $f_1=\log P(y_t\mid y_{t-1})$、$f_2=\log P(x_t\mid y_t)$，权重取 1。此时势函数等于 HMM 的转移乘发射，而 HMM 的概率本身已归一化，所以 $Z=1$。

14. 收尾

四句话收尾：

  1. 分词难在歧义与未登录词，规则方法只能处理「词典里有的、切法唯一的」情况。
  2. 统计方法从最短路径走到语言模型：先数边，再给整句打分，束搜索是工程上的折中。
  3. 序列标注把「切」换成「贴标签」，BMES 让词边界从标签里长出来，也能处理新词。
  4. CRF在整条标签序列上打分，用特征模板看整个观测；前向求 $Z$，维特比求最优，算法与 HMM 同构。

如果只用一句话记住这条线：分词从「找词」变成「给每个字找一个受邻居约束的标签」，CRF 只是把这个约束写成了一个可计算的分数。

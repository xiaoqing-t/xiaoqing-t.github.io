计算理论 · 第 6 集

计算理论：下推自动机

一句话主线：上一集用重写规则描述语言，这一集给文法配一台机器。下推自动机就是有限控制加一个后进先出的栈：读 0 压栈、读 1 弹栈，栈空就说明两边数量相等。它和上下文无关文法等价；闭包性质、五段泵引理和三个判定问题，构成了它的能力边界。

动手试：在浏览器里逐步运行 0ⁿ1ⁿ →

有限自动机只有一个当前位置，读过的东西不留下。上下文无关文法靠「结构」记住了两边同步，但它只是一套重写规则，不是一台能运行的机器。下推自动机补上这个缺口：状态还是有限的，额外给一条栈，深度不设上限。

0. 任务：读到一半，忘了数量

读 $0^n1^n$ 时，读到一半需要记住「已经读了多少个 0」。这个数没有上界，状态数却必须有限。有限自动机在这里必然失败，泵引理已经证明过。

栈提供了另一种记法：不要把数量记成数字，而是把每一个 0 压进栈。读 1 时弹一个 0，两边一一抵消。读完整串后栈空，就说明数量相等。栈的深度随输入增长，但控制器仍然只有有限个状态。

1. 栈：只在一端操作

栈是后进先出（LIFO）的存储：只能看栈顶、压栈、弹栈，不能访问中间。对 $0^n1^n$，规则只有两条：

  • 读到 0：压一个 0；
  • 读到 1：如果栈顶是 0，弹掉；否则这条路径失败。

关键不是「能不能存」，而是「只能按相反顺序取出」。输入先来 0、后来 1，栈后进先出，正好把最近的 0 和最近的 1 配对。括号、嵌套结构、递归调用都遵循同样的顺序。

2. 下推自动机：六元组

下推自动机（PDA）是一个六元组：

$$M=(Q,\ \Sigma,\ \Gamma,\ \delta,\ q_0,\ F)$$

  • $Q$：有限状态集；
  • $\Sigma$：输入字母表；
  • $\Gamma$：栈字母表，通常包含输入字母表和一个栈底符号；
  • $\delta$：转移函数；
  • $q_0\in Q$：初始状态；
  • $F\subseteq Q$：接受状态集。

转移函数看三样东西：当前状态、下一个输入字符、栈顶；给出新状态和新栈顶串：

$$\delta:Q\times(\Sigma\cup\{\varepsilon\})\times(\Gamma\cup\{\varepsilon\})\to\mathcal{P}(Q\times\Gamma^*)$$

输入字符可以是 $\varepsilon$，表示不读输入；栈顶也可以是 $\varepsilon$，表示不要求栈非空。结果是「状态 + 新栈顶串」的集合：压栈写成把新符号放到栈顶串前面，弹栈写成栈顶串去掉第一个符号。

接收的定义：从初始状态和空栈出发，读完整串后进入某个接受状态。只要存在一条路径做到，就接收；这就是非确定性。栈底符号 $ 不是六元组的一部分，它只是把「空栈」显式写出来，避免「栈空了还能不能继续」的歧义。

3. $0^n1^n$ 的四状态机器

用四个状态把上面的规则画成机器：

阶段读入栈顶动作下一状态
开始εε压 $$q_0$
压栈0任意压 0$q_0$
切换10弹 0$q_1$
弹栈10弹 0$q_1$
收尾ε$弹 $$q_2$（接受）

两条失败分支要看清：1 比 0 多时，栈顶是 $，弹不动；0 比 1 多时，输入读完栈里还剩 0，无法进入接受。两条都说明数量不相等。

4. 一个串怎么被接收

以 $0011$ 为例，一条成功路径在每一刻都可以写成「状态、剩余输入、栈」的三元组：

$$(q_0,0011,\varepsilon)\to(q_0,011,0)\to(q_0,11,00)\to(q_1,1,0)\to(q_1,\varepsilon,\varepsilon)\to(q_2,\varepsilon,\varepsilon)$$

每一步只看三样：当前状态、下一个字符、栈顶。任何一步没有匹配的转移，这条路径就死掉；但机器是非确定的，只要别的路径能走到接受，整个串仍被接收。

非确定性在 PDA 里不是「随机选择」，而是「同时探索所有可能」。文法那里是选一条规则展开，这里是对应地选一条转移；两边其实是同一件事的两种写法。

5. 文法到机器：用栈做最左推导

一个语言是上下文无关的，当且仅当某台 PDA 识别它。两个方向都要构造。

文法到机器，思路是用栈模拟最左推导。栈顶就是当前要处理的符号：

  • 栈顶是变元 $A$：非确定地选一条规则 $A\to w$，把 $A$ 替换成 $w$，最左符号放到栈顶；
  • 栈顶是终结符 $a$：与下一个输入字符比较，相同就弹掉，不同就失败；
  • 栈顶是栈底标记 $：输入也读完了，就接受。

栈里保存的是「还没展开的部分」，顺序与最左推导一致。每展开一个变元，就把它的右边按相反顺序压栈，保证最左符号先被处理。

6. 机器到文法：状态对变元

反方向更难。先把机器整理成规范形状：

  1. 只有一个接受状态；
  2. 接受之前把栈清空；
  3. 每一步要么只压一个符号，要么只弹一个符号。

然后给每一对状态 $(p,q)$ 造一个变元 $A_{(p,q)}$，表示「从 $p$ 的空栈走到 $q$ 的空栈，能读出的所有串」。规则分两类：

$$A_{(p,q)}\to a\,A_{(r,s)}\,b\,A_{(s,q)},\qquad A_{(p,q)}\to A_{(p,r)}\,A_{(r,q)}$$

第一类对应「读字符压栈、再读字符弹栈」：$a$ 压进去，$b$ 把它弹掉，中间和后面各用变元夹住。第二类对应「中途回到空栈」：一串在 $r$ 处分成两段，各自从空栈到空栈。

基础规则是 $A_{(p,p)}\to\varepsilon$：原地不动，什么也不读。所有从开始状态走到接受状态的 $A_{(q_0,q_f)}$ 并起来，就是这个 PDA 的语言。

7. 闭包：哪些运算保得住

上下文无关语言对并、连接、星号封闭，构造和正则语言一样，只是把自动机换成文法：

  • 并：新开始变元二选一，指向两套规则；
  • 连接：先第一套，再第二套；
  • 星号：空串，或者自我重复。

它和正则语言求交也封闭：两台机器同时跑，读一个字符时两边都动，状态对作为新状态。乘积状态数最多是两台机器状态数的乘积。

但它对交不封闭。反例：

$$L_1=\{a^nb^nc^m\},\qquad L_2=\{a^mb^nc^n\},\qquad L_1\cap L_2=\{a^nb^nc^n\}$$

前两个都是上下文无关语言，交出来却不是。由德摩根律，对补也不封闭：如果对交封闭，补再取补就能得到交，矛盾。

8. 五段泵引理

上下文无关语言的泵引理：存在泵长度 $p$，任何长度至少 $p$ 的串 $s$ 都能切成五段：

$$s=uvxyz$$

满足三个条件：

  1. $|vy|>0$：第二段和第四段至少一个非空；
  2. $|vxy|\le p$：中间三段总长不超过 $p$；
  3. 对所有 $i\ge 0$，$uv^ixy^iz\in L$：两段同时重复。

为什么是两段同时泵？证明看语法树。设每个节点最多 $b$ 个孩子，高度 $h$ 的树最多 $b^h$ 个叶子。取泵长度 $p$ 为「分支数上限的、变元数加一次方」：长度至少 $p$ 的串，树一定够高，最长路径上必有一个变元重复。

同一个变元 $A$ 在路径上出现两次，上下两个 $A$ 各自展开一棵子树；从下 $A$ 到上 $A$ 之间的叶子就是 $v$ 和 $y$，中间夹着 $x$。把下 $A$ 的子树替换成上 $A$ 的子树，就重复了一次 $v$ 和 $y$；反过来裁掉，就泵零次。两段必须同时动，嵌套结构才不会散。

9. $a^nb^nc^n$ 不是 CFL

取 $s=a^pb^pc^p$。泵引理给出某个切分 $s=uvxyz$，且 $|vxy|\le p$。

中间三段长度不超过 $p$，而每一段都是 $p$ 个同一种字母，所以 $vxy$ 最多覆盖两段：它不可能同时包含 a、b、c 三种字符。

泵一次以后，$v$ 和 $y$ 中至少有一段变长。由于只覆盖至多两段，三段的数量不可能仍然相等：要么 a 变多、b 和 c 不变，要么 b 变多，等等。于是 $uv^2xy^2z\notin L$，与泵引理矛盾。

结论：$a^nb^nc^n$ 不是上下文无关语言。注意泵引理只给必要条件：满足泵引理不一定是 CFL，它只能用来证明「不是」。

10. 三个判定问题

问题方法结论
接收（成员判定）转 CNF，枚举长度 $2n-1$ 的推导；或 CYK 动态规划可判定
空性从开始变元出发，看能否推出纯终结符串可判定
相等两个 CFL 是否相同不可判定

接收和空性可判定，方法都不复杂：CYK 是多项式时间，枚举推导是指数上界但仍然会停。相等不可判定，这一点和正则语言不同——正则语言先确定化再检查对称差，三个问题都能判定。

工程上因此有一条经验：能转成正则表达式或有限自动机的问题，尽量转；一旦需要完整 CFG 的相等判断，就要准备接受「没有通用算法」。

11. 工程边界

栈能记住任意深度的未完成嵌套，所以下面三类问题都能用 PDA 的思路建模：

  • JSON 与括号：遇到左括号压栈，遇到右括号弹栈，最后栈空；
  • 表达式：运算符优先级决定语法树的形状，解析器用栈或递归下降；
  • 递归调用：每次调用压一帧，返回时弹一帧，调用栈就是运行时的那条栈。

但语法对不代表语义对。CFG 只检查形状：类型是否匹配、变量是否越权、业务规则是否满足，都要另外检查。把语法分析和语义检查分开，是编译器前端的标准做法。

12. 常见错误

  1. 把栈当普通数组。栈只能访问栈顶；能随机访问，模型就变强了。
  2. 以为 PDA 是确定的。本文定义的 PDA 是非确定的；确定下推自动机（DPDA）只能识别一部分 CFL，两者不等价。
  3. 忘记 $\varepsilon$ 转移。不读输入也能改状态或改栈，这是非确定性的重要来源。
  4. 接收条件写错。必须读完整串后进入接受状态；读到一半进入接受不算。
  5. 以为 CFL 对交封闭。$a^nb^nc^n$ 是两个 CFL 的交，却不是 CFL。
  6. 把泵引理当充分条件。它只给必要条件，满足它不能证明是 CFL。
  7. 只泵一段。PDA 泵引理要求 $v$ 和 $y$ 同时重复；只动一段会破坏嵌套。
  8. 以为相等可判定。两个 CFL 是否相等不可判定，和正则语言不同。

13. 自测 8 题

  1. 下推自动机的六元组分别是什么？转移函数看哪三样输入？
  2. 为什么 $0^n1^n$ 用栈就能识别，而有限自动机不行？
  3. PDA 的「非确定」具体指什么？接收条件是什么？
  4. 文法到 PDA 的构造里，栈顶是变元和栈顶是终结符，分别怎么处理？
  5. PDA 到文法的构造里，$A_{(p,q)}$ 表示什么？两类规则各对应什么结构？
  6. CFL 对哪些运算封闭？对哪些不封闭？给一个反例。
  7. CFL 泵引理的五个段、三个条件分别是什么？为什么两段要同时泵？
  8. 为什么 $a^nb^nc^n$ 不是 CFL？接收、空性、相等三个问题各可不可判定？
答案
  1. 状态集、输入字母表、栈字母表、转移函数、初始状态、接受状态；转移函数看当前状态、下一个输入字符、栈顶。
  2. 栈的深度随输入增长，可以逐个记住 0；有限自动机的状态数固定，无法记住无界计数。
  3. 同一个局面可以有多条转移；只要存在一条路径读完整串后进入接受状态，就接收。
  4. 栈顶是变元：选一条规则，把变元替换成右边，最左符号放栈顶；栈顶是终结符：与下一个输入字符比较，相同就弹掉。
  5. 从 $p$ 的空栈走到 $q$ 的空栈能读出的所有串；第一类对应「压入再弹出」的夹住结构，第二类对应「中途回到空栈」的拆分结构。
  6. 对并、连接、星号封闭，与正则语言求交也封闭；对交不封闭，例如两个 CFL 交成 $a^nb^nc^n$；由德摩根，对补也不封闭。
  7. 切成 $uvxyz$；条件：$|vy|>0$、$|vxy|\le p$、$uv^ixy^iz\in L$；两段同时泵是因为它们由同一对重复变元夹住，单独动会破坏嵌套。
  8. $vxy$ 最多覆盖两段，泵一次后三段数量不可能仍相等；接收和空性可判定，相等不可判定。

14. 收尾

四句话记住这一集：

  1. 下推自动机 = 有限控制 + 栈：栈深不设上限，状态仍然有限。
  2. 文法与机器等价：栈顶变元就展开，栈顶终结符就比对。
  3. 闭包差在交：并、连接、星号封闭，交与补不封闭。
  4. 五段泵引理证明非 CFL：$v$ 和 $y$ 必须同时重复。

如果只用一句话记住它：栈记住未完成的嵌套，所以嵌套有深度，语言就有结构。下一章把栈也放开，给机器一条无限长的带子——图灵机。

自然语言处理 · 句法分析

句法分析：给句子画一棵树

一句话主线：句法分析就是给每句话找一棵树。树只有三样东西——成分、规则、词典；规则从树库抄出来，统一成乔姆斯基范式后用 CKY 三角表拼树；歧义交给 PCFG 的规则概率，评价看成分的 P/R/F1。

记号约定：非终结符用大写，比如 S、NP、VP；终结符就是具体的词，比如 the、flight。规则写成 A → B C，箭头右边是展开后的样子。中文里对应的是「句子」「名词短语」「动词短语」「冠词」，本文第一次出现时写全称，之后用符号。

0. 一排词看不出结构

先看一句话：

I prefer a morning flight.

把词一个个排开，只知道有五个词，看不出谁和谁是一伙的。画成树，结构立刻清楚：主语是 I，谓语是 prefer，宾语是 a morning flight；而 morning flight 本身又是一个整体，不是两个互不相干的词。

这句话的一棵简化树是：

S
├── NP
│   └── Pronoun → I
└── VP
    ├── Verb → prefer
    └── NP
        ├── Det → a
        └── Nominal
            ├── Noun → morning
            └── Noun → flight

句法分析（syntactic parsing）要做的，就是给定一句话和一套语法，找出这棵树。树有两个作用：向上，它说明整句话怎么组成；向下，它把每个成分覆盖的词标出来，后面的任务可以直接用。

1. 一棵树只有三样东西

树不是凭空画出来的，它由三块搭起来：

部分作用例子
语法成分句子里的一个整体单位NP、VP、Det
语法规则一个成分能由什么组成S → NP VP
词典一个成分能由哪个词充当Det → a / an / the

树的节点分两类：

  • 非终结符是中间节点，只能放成分，比如 S、NP、VP；
  • 终结符是叶子，只能放具体的词，比如 the、cat。

这两类不能混：中间节点写一个词，或者叶子写一个成分，都不是合法的树。树的最上面是根，通常是 S；从根往下每一层都是成分；最底下的叶子才是词。

2. 上下文无关，还是上下文相关

规则有一个关键约束：箭头左边只能是一个成分。

写法左边类型
NP → Det Nominal一个符号上下文无关语法（CFG）
VP NP → VP Nominal两个符号上下文相关语法（CSG）

「上下文无关」的白话是：一个成分怎么展开，只看它自己长什么样，不看左右邻居。「上下文相关」允许规则带条件，比如「只有当 VP 右边跟着一个 NP 时，才这样展开」。

上下文相关更贴近语言事实，但解析难度高很多。工程上的句法分析几乎都停在上下文无关这一档：表达能力够用，算法也成熟。

3. 规则从树库里抄

规则不是人一条条想出来的。最常见的做法，是从树库（treebank）里抄：树库是一批句子，每句话都有人工画好的树。

最著名的是宾夕法尼亚树库（Penn Treebank），大约一百万词，主要来自华尔街日报。它的用法很直接：

  1. 对每棵树，沿每条父子边抄一条规则，比如 S → NP VP、NP → Det Nominal；
  2. 把相同的规则合并，记下出现次数；
  3. 整个树库能抄出一万七千多条不同的规则，光名词短语就上千条。

注意「树库」不是「语料库」。语料库是原始文本；树库是在文本上又加了一层句法标注，成本高得多。后面讲 PCFG 时，规则概率也正是从这张计数表来的。

4. 先统一格式：乔姆斯基范式

规则一多，形状就杂，算法不好写。于是先做一步标准化，统一成乔姆斯基范式（CNF）。它只允许两种形状：

  • A → B C：一个成分拆成两个成分；
  • A → word：一个成分改写成一个词。

下面三种都要先改写掉：

不合格的规则问题改法
A → B C D右边三个成分拆成 A → B X，X → C D
A → B一个成分换一个成分把 B 的展开直接并进 A
A → word word右边两个词先引入词性节点，再用二元规则

改完以后，句子集合不变，但树会变。这种「生成能力一样、树结构可能不同」的关系叫弱等价；如果树也一一对应，才叫强等价。

这一步是后面 CKY 能写成统一递推的前提：每个格子只考虑「左一半 + 右一半」这一种拼法。

5. CKY：三角表按跨度生长

有了二元规则，就可以用一张三角形的表把树拼出来。以八个词为例：

the man saw the dog with a telescope

表的每一格代表一段连续的字，格子里放这段字能构成的成分。填充顺序只有一条：按跨度从小到大。

  1. 跨度 1：对角线，一个词一格，填入词性，比如 Det、N、V；
  2. 跨度 2：两格拼一格，看哪条规则能把左右两个成分合成一个；
  3. 跨度 3、4……：一路往上，直到最上面一格覆盖整句。

每一格的算法是：枚举所有切分点 $k$，把左半格 $[i,k]$ 和右半格 $[k+1,j]$ 的成分拿来，查规则表；能合成 $A$，就把 $A$ 写进 $[i,j]$。

举例：[saw] 是 V，[the dog] 是 NP，规则表里有 VP → V NP，于是 [saw the dog] 这一格可以填 VP。

如果最右上角那一格装着 S，说明整句分析成功；如果空着，就说明这套语法生成不了这句话。复杂度是 $O(n^3|G|)$：三层循环分别枚举起点、终点和切分点。CKY 由 Cocke、Kasami、Younger 三人在 1970 年前后提出，名字就是三个人姓氏的首字母。

6. 同一句话，不止一棵树

可现实是，一句话往往能画出好几棵树。经典例子：

the man saw the dog with a telescope

with a telescope 这个介词短语，可以挂在 dog 下面——「带着望远镜的那条狗」；也可以挂在 saw 下面——「用望远镜看见了那条狗」。两种理解都合法，两棵树都成立。

只用规则，没法替我们选：规则只回答「能不能」，不回答「有多可能」。歧义是句法分析绕不开的核心问题，也是后面引入概率的动机。

7. PCFG：给规则加概率

给每条规则加一个条件概率：给定左边的成分 $A$，它按这条规则展开的可能性有多大。

$$P(A \to \beta \mid A)=\frac{\mathrm{count}(A \to \beta)}{\mathrm{count}(A)}$$

分母是「左边为 $A$ 的所有规则出现次数之和」，分子是「这一条规则出现的次数」。因为分子分母同源，同一个左边的所有规则，概率加起来正好等于 1：

$$\sum_{\beta} P(A \to \beta \mid A)=1$$

概率不是人拍的，是从树库里数出来的。下面是一张示意表：

规则概率说明
S → NP VP1.00句子只有这一种拆法
NP → Pronoun0.30左边都是 NP，三条加起来 = 1.00
NP → Det Nominal0.40
NP → ProperNoun0.20
VP → Verb NP0.20左边都是 VP，这里只列两条，其余规则合计 0.30
VP → Verb0.50

语法就从「能或不能」，变成了「有多可能」。这套带概率的上下文无关语法叫 PCFG（概率化上下文无关语法）。

8. 树概率是规则概率连乘

一棵树的概率，是它用到的所有规则概率的连乘。假设树 $T$ 的规则是 $r_1,\dots,r_m$，那么：

$$P(T)=\prod_{i=1}^{m} P(r_i \mid \mathrm{LHS}(r_i))$$

同一句话的两棵树，用同一套 PCFG 算出来，数值会差很多。以 the man saw the dog with a telescope 为例：

树挂靠方式概率
Awith a telescope 修饰 dog$2.2\times10^{-6}$
Bwith a telescope 修饰 saw$6.1\times10^{-7}$

两者相差约 3.5 倍。概率大的那棵，就是模型给出的答案。注意这不是「语法上谁对谁错」，而是「在树库的统计下谁更常见」。

9. 概率版 CKY：每格多一行

算法几乎不用改：表格照旧，只是每格多记一个概率。合并的时候，把左右两半的概率相乘，再乘上这条规则自己的概率，然后和已经有的候选比大小，留下大的那个：

$$P(i,j,A)=\max_{k,\ A\to BC}\Big[P(i,k,B)\cdot P(k+1,j,C)\cdot P(A\to BC\mid A)\Big]$$

被淘汰的分支直接变灰，不用再展开。这样扫一遍，最右上角留下的就是概率最大的那棵树——和 HMM 里维特比的做法是同一个思路：每个状态只保留当前最优，不保留所有历史。

区别在于：普通 CKY 只问「这一格能不能装下 $A$」，概率版 CKY 还要问「装下 $A$ 的最好方式有多好」。前者是布尔值，后者是实数。

10. 怎么评价：看成分，不看整棵树

整棵树完全匹配太苛刻：错一条边，整棵树就判错。实践中看成分：如果模型给出的某个成分，和标准树里的某个成分覆盖同一段词、标签也一样，就算匹配。

把模型提出的成分集合记作 $P$，标准树的成分集合记作 $G$：

$$\mathrm{Precision}=\frac{|P\cap G|}{|P|},\qquad \mathrm{Recall}=\frac{|P\cap G|}{|G|}$$

$$F_1=\frac{2PR}{P+R}$$

只看覆盖范围、不管标签，叫无标签 F1（unlabeled）；范围和标签一起看，叫有标签 F1（labeled）。有标签更严格，数值通常低几个点。

情况范围标签算不算匹配
绿色相同相同有标签、无标签都算
黄色相同不同只有无标签算
灰色不同—都不算

F1 是准确率和召回率的调和平均，两个都高才算好。只看准确率，模型可以只提极少、极有把握的成分；只看召回率，模型可以把所有可能范围都报一遍。

11. 工具与现状

工程上早就有现成工具。伯克利的神经句法分析器（Berkeley Neural Parser）、斯坦福的分析工具（Stanford Parser），都是输入一句话，直接给出树；网上也有在线演示，粘贴一句就能看结果。

工具通常还会给出成分跨度：每个成分覆盖第几个词到第几个词。后面的任务——关系抽取、机器翻译、问答——需要的往往就是这个跨度，而不是整棵树的形状。

在这些标准数据上，现在最好的模型，有标签 F1 已经到 96.38。这个数字已经很高，但要注意它的边界：换个领域、换个标注规范，或者遇到口语、长句、嵌套结构，性能会明显下降。

12. 规则路线的三个死穴

不过这条路有三个绕不开的问题：

  1. 规则永远抄不全。树库里没出现过的搭配，分析器就分析不出来；语言是开放的，规则是封闭的。
  2. 歧义靠概率，概率错了就选错树。PCFG 的独立性假设很强，它不看词与词之间的具体搭配，只数规则。
  3. 树库标注成本极高。每句话都要人画树，规模上不去；标注规范还容易不一致。

所以后来，特征和概率都交给了神经网络：不再手写规则，也不再把结构限制在上下文无关这一档，而是让模型从数据里学表示和结构。这条线的下一站，是词向量。

13. 放回流水线

句法分析是传统 NLP 流水线的最后一站：

阶段输入 → 输出解决什么
分词字串 → 词切分歧义、未登录词
词性标注词序列 → 词性序列兼类词消歧
句法分析词序列 → 树成分边界、句法结构

它和分词、词性标注一起，构成了传统自然语言处理的完整流水线。每一站的输出都是下一站的输入，错误也会一路传下去——这也是后来端到端神经网络要解决的问题之一。

14. 常见错误

  1. 把中间节点写成词。中间节点只能放成分；叶子只能放词，两类不能混。
  2. 以为 CFG 的箭头左边可以写多个符号。左边多个符号就是上下文相关语法，不是 CFG。
  3. 把树库叫成语料库。树库带句法标注，成本远高于原始语料。
  4. 以为 CNF 只是换写法、树不变。句子集合不变，但树会变，这是弱等价。
  5. CKY 填充顺序乱。必须按跨度从小到大；先填长跨度，短跨度还没算出来。
  6. 以为 PCFG 的概率是人工设定。概率来自树库计数：该规则次数 ÷ 同一个左边的总次数。
  7. 算树概率只乘叶子规则。树里每条规则都要乘，包括 S → NP VP 这种概率为 1 的。
  8. 用整棵树匹配来评价。错一条边就全错；应按成分算 P/R/F1。
  9. 混淆无标签与有标签 F1。前者只看范围，后者范围加标签，数值不能直接比。
  10. 以为规则越多越好。规则多能覆盖更多句子，但也更容易过拟合树库，泛化未必更好。

15. 自测 8 题

  1. 一棵句法树由哪三样东西搭起来？中间节点和叶子分别放什么？
  2. CFG 和 CSG 的区别是什么？为什么工程上多用 CFG？
  3. 树库里的规则是怎么「抄」出来的？为什么光名词短语就有上千条？
  4. 乔姆斯基范式允许哪两种形状？改写后句子集合和树分别变不变？
  5. CKY 的填充顺序为什么必须按跨度从小到大？最右上角装着什么才算成功？
  6. PCFG 里同一左边的规则概率为什么加起来等于 1？概率从哪来？
  7. 一棵树的概率怎么算？两棵树 $2.2\times10^{-6}$ 与 $6.1\times10^{-7}$ 相差约几倍？
  8. 有标签 F1 和无标签 F1 差在哪？F1 为什么用调和平均？
答案
  1. 语法成分、语法规则、词典。中间节点放成分（非终结符），叶子放具体的词（终结符）。
  2. CFG 的箭头左边只能有一个成分；CSG 允许左边带多个符号或上下文条件。CSG 更贴近语言，但解析难得多，工程上几乎都停在 CFG。
  3. 沿每棵树的每条父子边抄一条规则，再把相同的规则合并计数。名词短语规则数量多，是因为名词短语的修饰结构非常多样。
  4. 只允许 A → B C 和 A → word。改写后句子集合不变，树会变，这叫弱等价。
  5. 因为每一格由左半格和右半格拼成，短跨度没算出来，长跨度就没有输入。最右上角装着 S 才算整句分析成功。
  6. 每条规则的概率是「该规则次数 ÷ 同一个左边的总次数」，同一个左边的所有规则共享分母，所以加起来等于 1。概率从树库统计来。
  7. 把所有用到的规则概率连乘。$2.2\times10^{-6} \div 6.1\times10^{-7}\approx3.6$，约 3.5 倍。
  8. 无标签只看覆盖范围，有标签还要标签相同。F1 是 P 和 R 的调和平均，任何一项低都会把 F1 拉低，避免只看单项。

16. 收尾

五句话记住这条线：

  1. 树由成分、规则、词典搭起来；中间放成分，叶子放词。
  2. 规则从树库抄，先统一成乔姆斯基范式，句子集合不变、树会变（弱等价）。
  3. CKY 用三角表按跨度生长，每格由左格 + 右格 + 规则拼成。
  4. PCFG 给规则加概率，树概率是规则概率连乘，概率版 CKY 每格取最大。
  5. 评价看成分的 P/R/F1；规则路线的尽头是覆盖、歧义和标注成本，后来交给神经网络。

如果只用一句话记住它：句法分析不是背语法，而是拿一套从树库学来的规则，给每句话找出最可能的那棵树。上一集《BPE》把词切成词元，这一集把词拼成结构；再往前，是《中文分词与 CRF》和《词性标注与 HMM》。

Selected work

Terminal Coding Agent

C · ~2.3k lines · 2026

A terminal coding agent written from scratch in C. The hard part is not calling the model: it is keeping the main loop unchanged while tools, history, and execution order change. It has a tool registry, one sandbox function guarding every file path, parallel read-only execution, and two context policies — lossless offloading versus lossy summarization.

Multimodal EEG Pipeline

Python · 10 datasets · 380+ hours

A QC-first preprocessing pipeline for EEG, ECG, and EOG. It checks units, channel statistics, and reference electrodes before touching the signal, produces reproducible QC plots, and writes per-subject HDF5. Packaged as a reusable skill so the decision rules — not only the scripts — carry over to the next dataset.

MIPS Single-Cycle CPU

Verilog · 610 lines RTL

A single-cycle MIPS processor built module by module: ALU, register file, control unit, datapath, and top level. Seven testbenches, synthesized to a bitstream, and run on an FPGA.

Mar 2026 – present · Shanghai Jiao Tong University

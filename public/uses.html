我在用什么

一份会过期的清单。只写经常用、并且确实改变了工作方式的东西；没提到的，多半是装了没用。

01

机器

笔记本
ASUS Vivobook Pro 15（N6506MV）
处理器
Intel Core Ultra 9 185H
显卡
NVIDIA GeForce RTX 4060 Laptop · Intel Arc 核显
内存
16 GB
系统
Windows 11 · 日常终端用 Git Bash
运行时
Node 24 · Python 3.13

CUDA 的活走独显：深度学习作业、BIOT 复现和数据预处理都在这一台上跑。

02

写东西

Obsidian
所有笔记放在同一个 vault，按活跃线、课内、项目和调研分区。
插件
PDF++ 读课件与论文，Homepage 固定首页，Style Settings 调排版；活跃线看板用核心插件 Bases。
节奏
每周六复盘一次：看板上按 updated 算停滞天数，超过两周标红；自动提交.ps1 定时把改动落盘。
去向
笔记不是终点。课内长文会被改写成网站笔记，再压成 60 秒竖屏短片。

03

写代码

编辑器
Qoder，VS Code 系；长任务和批量改动交给终端里的 agent。
网站
Vite 8 + React 19 + TypeScript 7，样式全部手写，没有 UI 框架。
构建
首页在构建后内联成一个自包含 HTML；笔记是手写静态页，URL 不随框架变。
内容
notes.json 是书目的唯一来源；公式用自托管的 KaTeX，不走 CDN。
部署
推 main，GitHub Actions 构建并发布到 GitHub Pages。

04

做视频

动画
Manim Community，固定 1080×1920、30 fps、9:16。
配音
edge-tts，音色 zh-CN-YunxiNeural，语速 -2%；逐句合成并记录真实时长。
后期
Python 对齐音轨，imageio-ffmpeg 混流；字幕输出 WebVTT，封面单独生成。
为什么
每一幕的停留按配音真实时长补齐。改一句文案只需重跑，不用在剪辑软件里手动对轨。

05

字体与配色

字体
标题用 Source Han Serif SC / Noto Serif SC，正文用系统无衬线，元信息用等宽。
颜色
纸白 #faf7f1、墨 #211d19、锈红 #a84027、分隔线 #e5dccd。
视频
沿用同一组颜色，字体换成正文字体 Microsoft YaHei，保证竖屏小字清楚。
理由
长文用纸白比纯白耐看；全站只留一个强调色，链接、序号和小标题都用它。

06

不做

  • 不接访问统计，不装第三方脚本。
  • 不引 UI 框架，也不把笔记正文搬进 React。
  • KaTeX 及其字体文件自托管，不依赖 CDN。

少一层依赖，就少一个以后要修的东西。

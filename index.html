01关于我

我在做什么

主修计算机科学,目前在 BCI 实验室参与 EEG 数据的采集与预处理。正在系统学习深度学习基础(CS231n),目标是打通「算法理解 → 代码实现 → 领域应用」的完整链路。

我关心的问题

当 AI 能写大部分代码时,工程师真正的竞争力在哪里?我的答案是在于领域知识 + 亲手实现的能力。所以我在刻意练习「不靠 AI 也能写出来」——从理解算法、到独立实现、再到沉淀成可复用的工具。

我热爱的事

创造与学习。无论是写代码、做设计,还是弄明白一个概念后把它讲给别人——这种「从无到有、从混沌到清晰」的过程最让我投入。

02项目

AI Agent

Agent 架构研究

基于「学习—复现—修改」的思路研究 agent 架构:main 主流程、LLM 对话、client、工具调用、线程池、上下文管理、技能与总结、offload 代理等核心组件。目标是拆解后能亲手重写一遍。

BCI · EEG

EEG 数据预处理管线

为实验室采集并预处理 EEG 数据集:滤波、归一化、特征提取、伪迹去除。把重复的工程步骤沉淀为可复用、配置驱动的 skill。

  • 先 QC 再预处理,保证数据质量
  • 多通道 EEG 批量处理,HDF5 输出
Deep Learning

CS231n 深度学习

从零实现 CNN 的 forward / backward、损失函数与训练循环。不借助 AI 逐行手写,以提升编码基本功与对深度学习的直觉。

  • 线性分类器 → 全连接网络 → CNN
  • 与 BCI 的信号表示学习相互印证
